# Campus Inspection Dashboard

## Preview

Extract the ZIP and open `index.html`. The compiled files in `dist/` are included. Leave the demo credentials blank if you prefer. Select **Log in** to start the preview, or choose **Skip and open dashboard** on the startup screen to enter immediately.

## Edit

Run `npm ci` and then `node build.mjs` to rebuild after an edit. The styles for the workstation theme are in `src/console.css`. The original routes, dashboards, and sample data are kept. The hero artwork in `src/RoverSchematic.jsx` is a concept schematic of the robot.

This is the supplied frontend demonstration. It uses sample data.
